# Alphataurus 

A virtual machine executing x86-like bytecode with an assembler and a linker, implemented in Go.

Currently very unfinished, a lot of stuff is still not done.

In the future I'd like to write an archiviser and a pseudo-kernel (a bunch of syscalls) that would allow for std libraries to be written.

Some semblance of a documentation should be written in the future but I'm a lazy bastard so don't get your hopes up.
